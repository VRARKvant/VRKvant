# 📝 Шпаргалка: Как создавать контент для VR Kvant

Этот документ является **единым и полным руководством** по оформлению статей, уроков и шпаргалок на нашем портале. Мы используем Markdown со специальными интерактивными расширениями.

Сверяйтесь с этим документом, если забыли, как вставить галерею, видео или стилизовать блок внимания.

---

## 1. Метаданные статьи (Frontmatter)

Каждая статья **обязательно** должна начинаться с блока метаданных (отделенного тремя дефисами `---`). Это указывает сайту, куда положить статью и как ее отображать.

**Базовый набор для обычной статьи:**
```yaml
---
title: Название статьи (Отображается в меню)
module: Название модуля (Группировка в меню, например "Основы Unity")
order: 1 (Порядковый номер в меню)
type: article (Доступные типы: article, lesson, cheat, intro, track)
authors: 'Ваше Имя' (Опционально)
---
```

**Дополнительные параметры (для Интро/Треков/Игр):**
Если вы создаете вводную статью раздела (`type: intro`) или добавляете игру, используются специальные поля:
```yaml
---
name: Короткое имя трека (Например: Unity, Blender)
icon: Иконка (Например: fab fa-unity или ссылка на SVG)
colorClass: CSS класс для заливки (Например: bg-zinc-800)
description: Краткое описание (Обычно для игр и проектов)
cover: Ссылка на картинку-обложку (Для игр)
url: Путь к файлу (Например: games/pixelart/index.html)
---
```

## 2. Базовое форматирование текста

Все стандартные возможности Markdown поддерживаются:

### Заголовки
Используйте решетки (`#`). Старайтесь использовать один заголовок `<h1>` (одна решетка) на статью — обычно это название. Для разделов используйте `##` и `###`.

```markdown
# Главный заголовок статьи
## Раздел 1
### Подраздел 1.1
```

### Списки и Выделение
Используйте звездочки `*` или дефисы `-` для маркированных списков, и цифры `1.` для нумерованных. Для выделения жирным оберните текст в `**две звездочки**`.

```markdown
Для работы нам понадобится:
1. Скачать **Unity Hub**.
2. Создать новый 3D проект.
   - Убедитесь, что выбрали правильную версию.
```

## 3. Умные цветные цитаты (Callouts)

Парсер сайта автоматически раскрашивает блоки цитат в зависимости от их первого слова. Используйте символ `>` перед строкой.

> **Важно:** Блок станет красным/оранжевым. Используйте для критических предупреждений. 
> *(Ключевые слова: Важно, Внимание, Предупреждение)*

> **Совет:** Блок станет зеленым. Используйте для лайфхаков и горячих клавиш.
> *(Ключевые слова: Совет, Лайфхак)*

> **Заметка:** Блок станет синим. Используйте для дополнительной теоретической информации.
> *(Ключевые слова: Заметка, Информация)*

> Если не использовать эти слова, цитата будет стандартного серо-фиолетового цвета.

## 4. Кастомные интерактивные теги (Виджеты)

Это наша собственная разработка. Вы можете вставлять сложные интерактивные виджеты, используя синтаксис в квадратных скобках.

**⚠️ Важное правило:** Всегда оставляйте **пустую строку** ДО и ПОСЛЕ кастомного тега, иначе он может не отрендериться.

### 🖼️ Галерея (Слайдер изображений)
Идеально для пошаговых инструкций (например, настройка параметров материала).
* **Синтаксис:** `[gallery: путь_к_картинке1 | путь_к_картинке2]`

```text
[gallery: img/unity/step1.png | img/unity/step2.png | img/unity/step3.png]
```

### 🌓 Слайдер "До и После" (Сравнение)
Позволяет пользователю тянуть ползунок, сравнивая два изображения. Первая картинка будет сверху ("До"), вторая снизу ("После").
* **Синтаксис:** `[compare: путь_до | путь_после]`

```text
[compare: img/graphics/no_postprocess.jpg | img/graphics/with_postprocess.jpg]
```

### 🎥 Вставка Видео
Поддерживает прямые ссылки на `.mp4` или ссылки на YouTube.
* **Синтаксис:** `[video: ссылка_на_видео]`

```text
[video: https://www.youtube.com/watch?v=nhXbdBy1DTU]
```

### 🧩 Unreal Engine Blueprints
Красивое отображение логики Blueprint через сервис `blueprintue.com`.
* **Синтаксис:** `[blueprint: ссылка]`

```text
[blueprint: https://blueprintue.com/blueprint/yroj2grr/]
```

### 🎮 Вставка игр, 3D-моделей или других сайтов (iframe)
Позволяет встроить любую внешнюю веб-страницу или локальную HTML-игру (напр. Pixel Art). Обязательно укажите высоту блока через `|`.
* **Синтаксис:** `[html: путь_или_ссылка | высота]`

```text
[html: games/pixelart/index.html | 600px]
```

## 5. Вставка блоков кода

Для вставки программного кода (C#, Python, C++) используйте три обратных апострофа и название языка для подсветки синтаксиса.

**Как писать:**


## 6. Золотые правила автора (Лучшие практики)

1. **Относительные пути:** Всегда используйте пути вида `img/folder/image.png` вместо `http://.../img/...`. Это гарантирует, что сайт будет работать в офлайн-режиме (PWA).
2. **Оптимизация медиа:** Обязательно сжимайте картинки (через TinyPNG или аналоги) перед загрузкой. Тяжелые картинки убивают скорость загрузки.
3. **Структура:** Не делайте гигантские абзацы текста. Разбивайте теорию на короткие списки, добавляйте цитаты-советы и скриншоты.
